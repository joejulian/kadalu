= Install Kadalu Operator and CSI Pods using local Yaml and Container images.

**Note**: Private registry support is available only with Kadalu `>=0.8.14`

== Start the Private Container registry

----
docker run -d -p 5000:5000 --restart=always --name registry registry:3
----

This command is suitable for local testing. Configure TLS, authentication, and
persistent storage before using a registry in production.

== Download the container images to local registry

Mirror the Kadalu images and the pinned CSI sidecar images into the custom
registry. The examples use `registry.example.invalid:5000` as a placeholder;
replace it with your registry and replace `<kadalu-version>` with the release
being installed.

Use a tool that preserves multi-architecture image indexes and digests. For
example, with `skopeo`:

----
skopeo copy --all docker://ghcr.io/joejulian/kadalu-csi:<kadalu-version> \
  docker://registry.example.invalid:5000/kadalu/kadalu-csi:<kadalu-version>
skopeo copy --all docker://ghcr.io/joejulian/kadalu-operator:<kadalu-version> \
  docker://registry.example.invalid:5000/kadalu/kadalu-operator:<kadalu-version>
skopeo copy --all docker://ghcr.io/joejulian/kadalu-server:<kadalu-version> \
  docker://registry.example.invalid:5000/kadalu/kadalu-server:<kadalu-version>
skopeo copy --all \
  docker://docker.io/library/busybox:1.37.0@sha256:9db7b59979c38555a39def84a31fb98b5296952f9e3afd4f6f11f05b07adfab0 \
  docker://registry.example.invalid:5000/library/busybox:1.37.0

skopeo copy --all --preserve-digests \
  docker://registry.k8s.io/sig-storage/csi-node-driver-registrar@sha256:f9de845b170155199f2a2a3f9531cf13d78e31235e9db6b6582a8b0db0a50dad \
  docker://registry.example.invalid:5000/sig-storage/csi-node-driver-registrar:v2.17.0
skopeo copy --all --preserve-digests \
  docker://registry.k8s.io/sig-storage/csi-provisioner@sha256:a4b0b1a37605b7b04a293e136edf7006ec1786a8eb3f4e5a945f81d667dcc371 \
  docker://registry.example.invalid:5000/sig-storage/csi-provisioner:v6.3.0
skopeo copy --all --preserve-digests \
  docker://registry.k8s.io/sig-storage/csi-resizer@sha256:ea1d25e23479000c7e8eeb92d827df66258df4e482ca054c5e7ce3fc0f5c41a5 \
  docker://registry.example.invalid:5000/sig-storage/csi-resizer:v2.2.1
skopeo copy --all --preserve-digests \
  docker://registry.k8s.io/sig-storage/livenessprobe@sha256:06da0d5b8908072f2e4522692aee8dc119fba7247a9658497e1153992cd777e9 \
  docker://registry.example.invalid:5000/sig-storage/livenessprobe:v2.19.0
----

Kadalu declares `attachRequired: false`, so the current deployment does not use
the external-attacher sidecar.

== Generate Manifest files

The Kadalu image registry and CSI sidecar registry are configured separately.
Render the local Helm chart with both registries set to the mirror:

----
helm template kadalu ./helm/kadalu \
  --include-crds \
  --namespace kadalu \
  --set operator.enabled=true \
  --set-string global.kadaluVersion=<kadalu-version> \
  --set-string global.image.registry=registry.example.invalid:5000 \
  --set-string global.image.repository=kadalu \
  --set-string global.csiSidecarRegistry=registry.example.invalid:5000 \
  > manifests/kadalu-operator-private-registry.yaml
----

The Kadalu application images and BusyBox logging helper follow
`global.image.registry`. CSI sidecars follow `global.csiSidecarRegistry`, so a
fully disconnected deployment must mirror and configure both registries.

== Install Kubectl extension

----
curl -fsSL https://github.com/joejulian/kadalu/releases/latest/download/install.sh | sudo bash -x
----

== Install Kadalu Operator and CSI

----
kubectl kadalu install \
  --local-yaml=./manifests/kadalu-operator-private-registry.yaml
----
